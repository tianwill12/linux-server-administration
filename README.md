
# Linux Server Administration

## Project Overview
This project focuses on practical Linux server administration using Ubuntu Server. It covers server configuration, remote access, user management, firewall security, and system monitoring.

## Project Objectives
- Understand Linux server administration.
- Configure and manage Ubuntu Server.
- Implement secure remote access using SSH.
- Manage users and file permissions.
- Configure firewall rules using UFW.
- Monitor server resources and performance.

## Technologies & Tools
- Ubuntu Server
- Linux Command Line
- OpenSSH
- UFW Firewall
- Bash Scripting
- VMware Workstation
- Git & GitHub
