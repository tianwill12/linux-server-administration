
# Ubuntu Server Installation

## 1. Project Overview

This document contains the installation and initial configuration of Ubuntu Server for the Linux Server Administration project.

## 2. Objectives

- Install Ubuntu Server using VMware Workstation.
- Configure basic server settings.
- Understand Linux server environments.
- Verify the server installation.
- Prepare the server for further administration.

## 3. Environment and Tools

| Component | Description |
|---|---|
| Operating System | Ubuntu Server |
| Virtualization | VMware Workstation |
| Terminal | Linux Command Line |
| Documentation | GitHub |

## 4. Installation Procedure

The installation process will include:

1. Downloading the Ubuntu Server ISO image.
2. Creating a virtual machine in VMware.
3. Configuring CPU, RAM, and storage.
4. Installing Ubuntu Server.
5. Configuring the hostname and user account.
6. Completing the initial system setup.

## 5. Initial System Verification

The following commands will be used to verify the installation:

```bash
lsb_release -a
hostnamectl
ip addr
df -h
free -h
```

Screenshots and installation results will be added after completing the practical installation.
